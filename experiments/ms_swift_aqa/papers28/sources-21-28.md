# 第 21–28 篇的实现和实验条件

| 编号 | 方法 | Swift 接入和来源 |
|---|---|---|
| 21 | BoRA | 复用项目已有的 `experiments.ms_swift_aqa.branches.bora.BoRABranch`（原 `west_adapters.bora`），每个块对有一个归一化指数对角增益，配置为两块。2026-11-21 论文与作者主页所列仓库均返回 404，因此该条以论文为实现依据。测试显式拼接每个块的更新矩阵并比对前向、随机非零权重重载及增益梯度。[论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/e8b0c97b34fdaf58b2f48f8cca85e76a-Abstract-Conference.html) · [作者主页](https://leopold1423.github.io/) |
| 22 | IGU-LoRA | 接入作者的候选秩剪枝和固定掩码重新训练。依公开代码，每个微批从 20 个积分路径节点抽样，将三因子更新乘以路径系数的三次方，用灵敏度 EMA 与绝对偏差 EMA 的比值选择有效秩。中间剪枝点把未选中的奇异值置零，下一微批仍可使它恢复。最终 SFT 才固定 rank mask。剪枝阶段按作者训练入口在每个微批加入完整的非对角正交正则，同时将交叉熵按累积数归一化。在真实 GQA 投影上按单个秩分量实际占用的参数数目计算预算。初始秩 16，目标约相当于平均秩 8。为了匹配小规模语音实验，将预剪枝设为 64 次更新，用 256 个源训练样本，随后用原清单早停。记录实际有效参数数与物理存储参数数。这一实现遵循作者发布的随机估计路径。论文还描述了包含两个端点的数值积分估计。[论文](https://arxiv.org/abs/2603.13792) · [作者实现](https://github.com/Cuixuans/igulora/tree/3f5ba10a6646c81c557e4669b14b072f76822085) |
| 23 | LoFT | 原样使用作者的 `LoFTAdamW` 和矩函数，保留 MIT 许可证。采用单位缩放、交替更新、两阶矩重投影和投影后更新。发布版回调将 clipping 函数从错误模块导入。以同版本 `clipping.py` 的显式完整梯度裁剪为参照，接入层用 rank 维 Gram 矩阵计算相同的 Frobenius 范数，并复用作者的梯度缩放函数，A/B 两种交替更新方向都做了数值核对。优化器重载同时恢复轮到的因子和重投影用的上一步权重。训练启用这一专用裁剪并关闭 Trainer 自带裁剪。[论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/7428310c0f97f1c6bb2ef1be99c1ec2a-Abstract-Conference.html) · [作者实现](https://github.com/tnurbek/loft/tree/148998d98f901cd7744db7baa5b2b4868fa16bf0) |
| 24 | LoRA-Mixer | 以 ICLR 补充代码 `llama3-train.py` 为依据，在 36 层 Q/K/V/O 投影处加入每 token 路由。源 AVQA 的 Which、Come From、Happening、Where 各抽 64 个样本，分别训练 rank 2 专家，然后在共用训练清单上软路由联合训练。每层有四个专家和宽 256 的路由 MLP。根据作者实现，输出按所有专家的 softmax 加权，top-3 用于路由负载统计。RSL 按论文式 5 对有效 token 取平均，并按官方模型在全部已路由投影取均值。有效 token 均值使同一样本的补齐长度不会改变损失。保留第一阶段专家参数作为式 11 的距离约束。原始 GitHub 在查验的提交仅包含 README 与许可证，会议的补充包内有模型与训练源码，SHA-256 为 `2b87e32bd63ab60fb13a4b52294f953f9dba172dae9146a240cd60a3fc9dc486`。[论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/18610cbcd1da57854aa05ebdc5cd3168-Abstract-Conference.html) · [官方补充代码](https://proceedings.iclr.cc/paper_files/paper/2026/file/18610cbcd1da57854aa05ebdc5cd3168-Supplemental-Conference.zip) |
| 25 | LoRAGen | 直接复用作者 decoder-only LAE、按模块区分的 MoE 解码器、Transformer 去噪器和 `GaussianDiffusion1D`。论文式 2 针对完整 `BA`，公开训练损失却比较各个因子；这里按论文用小型 Gram 矩阵精确计算完整更新的夹角，谱损失使用压缩 QR 与 SVD。生成器拟合上行四个专家的 Q/V 参数，所有 36 层与 Q/V 宽度均取自 Omni。用冻结的 Omni 文本解码器编码任务描述，辅助条件沿用作者实现的全 1 向量。源生成描述在实验前固定为音频事件的原因与先后关系，专家训练排除 Why/Before Next 等非专家题型及对应的整段原始视频。生成一个 rank 2、单位缩放的原生 PEFT checkpoint，对两个目标集重载同一份。此次专家库只有四种 AVQA 子任务，测的是这一小库上的条件生成迁移。发布研究另用了 FLAN-T5/Gemma 任务库。源专家拟合、LAE、扩散训练时间与参数分别记录。小专家库使用 512 次 LAE 更新、1024 次去噪器更新、500 个扩散时刻和 64 次 DDIM 采样。按官方推理脚本采用最终去噪器的 model 权重；源任务不执行周期性 EMA 试评或 checkpoint 搜索。源专家重建、描述正常顺序和轮换后的生成夹角是诊断量。两次生成诊断共用固定噪声。两测试集均不用于选择描述、噪声或权重。[论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/fc7c087b5e965075c8946b9ff57e3d64-Abstract-Conference.html) · [作者实现](https://github.com/tsinghua-fib-lab/LoRAGen/tree/911a738e63439732e94897f1aefd0d92123c4d9a) |
| 26 | RaLoRA | 实现论文主方法，为每层按平均完整投影梯度的奇异值熵确定块数。每块有独立的 A/B，对角拼接。固定每块的参考秩后，单层可训练参数数始终为 `rank*(in+out)`。64 个源训练微批、每批一条，梯度搬到 CPU 累加，返回设备逐层计算完整奇异值。checkpoint 自带各层块数，评估可独立恢复。补充代码还实现了引入跨层敏感度预算分配的 RaLoRA-Pro。本实验使用基础版本。补充 ZIP 的 SHA-256 为 `a40c3c99d6016e8ca37074f47f545fb6350c9b37836f2d9ba8e232ec95205bdf`。[论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/5b4b967d4222d87fa5b28b6ec7144058-Abstract-Conference.html) · [官方补充代码](https://proceedings.iclr.cc/paper_files/paper/2026/file/5b4b967d4222d87fa5b28b6ec7144058-Supplemental-Conference.zip) |
| 27 | Stable-LoRA | 将作者优化器的 A 缩减步骤接到普通 AdamW 更新之前。每对因子单独比较按大小归一化后的范数。一旦达到作者的稳定条件，该层后续停止缩减。学习率和梯度累积沿用共用协议，缩减系数 0.001 位于论文对照范围内。逐层停止标志随优化器状态恢复。[论文](https://arxiv.org/abs/2603.05204) · [作者实现](https://github.com/yize-wu/Stable-LoRA/tree/fadecb58739d34b9da51ef3f4f50bc1d38b480bb) |
| 28 | LoKRA | 对普通乘积 `BA` 按作者 `finetune_krank.py` 增加训练损失。每次在 A 的列和 B 的行内各随机采样，取正则化 Gram 矩阵的负对数行列式，保留作者对采样大小与层数的归一化。系数 0.001 来自作者示例。使用基础 LoKRA，论文中分别另有 Khatri–Rao 因子构成的增强版本 LoKRA+。此前报告的 PEFT LoKr 对应另一种 Kronecker 方法。[论文](https://proceedings.mlr.press/v306/xu26ae.html) · [作者实现](https://github.com/AMD-AGI/LoKRA/blob/9e118de65047653ced8c968d2ac0f55032bff5d7/finetune_krank.py) |

LoRAGen 的四份源权重取自 Q/K/V/O 专家中的 Q/V 因子。生成器与最终的语言模型仅交换 Q/V 因子。其 `generation.json` 分别记录单个专家与全部专家的参数量、LAE 和扩散生成器的参数量、交付给两个目标任务的 adapter 参数量，以及各训练阶段时间和 GPU 峰值。其他方法中，RaLoRA 的校准、IGU-LoRA 的剪枝和 LoRA-Mixer 的专家预训练成本写入各自的 `initialization.json`。

固定版本内的源码许可和搬运范围也已核对。LoFT 优化器和矩计算文件及其 MIT 许可证与作者归档逐字节一致。LoRAGen 的 LAE、位置函数和 Apache-2.0 许可证逐字节一致，去噪 Transformer 修正上游将 `util.py` 写成 `utils` 的导入，扩散源码仅移除未使用的 Trainer 和依赖，保留函数及类的语法树一致。LoRA-Mixer 与 LoKRA 的公开仓库列出 Apache-2.0。IGU-LoRA、Stable-LoRA 的所列提交以及 RaLoRA 与 LoRA-Mixer 的会议代码压缩包中未找到单列的许可证文件。对于这些方法，项目使用按公式及行为独立编写的 Swift 接入层；前述原样引入的文件均保留了对应许可证。

配置均位于 [configs](configs)。每种方法的实际目标集结果、完整性检查和原始日志由统一实验驱动写入当前运行目录。[训练与评估驱动](run.py)
