# 面向 ACL 的判断

写于 2026-11-22。依据是 [`DIAGNOSIS.md`](DIAGNOSIS.md) 的审查结果和当天的文献检索。文献部分只读了摘要级内容和个别页面的要点，投稿前需要逐篇精读核实；下文凡涉及他人论文的表述都应以原文为准。

## 1. 现在是否具备投稿贡献

**不具备。** 理由按重要性排列：

1. 没有任何一个预先确定的评测上 CoTA 稳定优于同预算 LoRA；IEMOCAP 准确率上反而低于 LoRA（按对话聚类的区间不含零；UAR 的区间跨零）。
2. 方法名里的 Conditional 没有实验对应物：门在数值上不起作用（DIAGNOSIS §1.1）。
3. 仅有的正面观察（长配对开关差 +8.33 pp）是单种子、单检查点、合成任务、未校正多重比较。
4. 评测集被反复观察；主比较单种子；多个基线未调参。
5. 与已有工作的边界没有划清（见下节）。

这不等于方向没有价值，而是说**目前的证据既没有支持也没有否定它**。[`PROTOCOL.md`](PROTOCOL.md) 的两个主比较约一天单卡就能给出明确答案。

## 2. 相关工作核对

| 工作 | 做了什么 | 与 CoTA 的重合 | CoTA 需要证明的差别 |
|---|---|---|---|
| Pay More Attention To Audio（MATA），[arXiv:2509.18816](https://arxiv.org/abs/2509.18816) | 在中间层直接提高对音频 token 的注意力权重，缓解音频—文本注意力失衡 | 动机相同（文本主导）；CoTA 的 `E[V\|audio]` 重归一化本质上也是放大音频读出 | 学习到的差分读出是否优于直接放大注意力；`ctrl-audio-mean` 对照正是为此 |
| Audio-Specialist Heads for Adaptive Audio Steering，[arXiv:2603.06854](https://arxiv.org/abs/2603.06854) | 用可解释性方法找出少数"音频专家"注意力头，据其音频注意力份额做自适应引导 | 同样在 head 级别利用音频注意力信号 | CoTA 对所有 head、所有层一视同仁；需说明为何不需要选头，或把选头作为强基线 |
| Who Wins the Conflict?，[arXiv:2606.18924](https://arxiv.org/abs/2606.18924) | 机制分析：文本通路并未抹掉音频信息，而是抑制它；用 back-patching 在推理时缓解 | 为"在后层把音频表示重新读出来"提供了机制依据 | CoTA 可引用其作为动机，但要证明训练式读出相对免训练干预的增益 |
| A Closer Look at Failure Modes in Temporal Understanding of LALMs，[arXiv:2606.17417](https://arxiv.org/abs/2606.17417) | 在最后一个 prompt token 上干预对音频的注意力；发现**在音频 token 之间重新分配**比单纯增加音频注意力总量更有效 | 干预位置与 CoTA 相同（最后一个 prompt token） | 这对 CoTA 的设计是直接的反面提示：CoTA 保持音频内部的注意力分布不变，只改变模态间的相对权重 |
| MaLoRA: Gated Modality LoRA，[arXiv:2510.26721](https://arxiv.org/abs/2510.26721) | 在解码器 `k_proj` 上加视觉/文本两条 LoRA 分支，用按 token 的门控混合，并加分布对齐正则，针对多模态模型的文本偏置 | "模态门控的 LoRA"这个概括已被占用（视觉—文本） | CoTA 的不同点只能是：音频、作用于 O 投影、用注意力聚合差而非隐状态做输入、只在答案位置 |
| TopLoRA，[arXiv:2510.23123](https://arxiv.org/abs/2510.23123)（已在本仓库 28 篇之列） | LoRA 权重写成 `B Σ_X A`，`Σ_X` 是由输入 token 生成的对角阵 | CoTA 的 `m ⊙` 就是秩空间里的输入相关对角门 | 门控形式本身不是新贡献；新意只能在"门的输入是什么" |
| Modality-Gated Deep Adapters，[arXiv:2609.26182](https://arxiv.org/abs/2609.26182) | 按输入是否含某模态做二值门控，保证其他模态上输出与基座逐位一致 | "只在该起作用的地方起作用、其余不动"的思路 | 与 DIAGNOSIS 的 H6（位置受限以减少负迁移）相关，应作为对照或引用 |
| Tracing Audio Grounding and Answer Selection in Audio LLMs，[arXiv:2609.04637](https://arxiv.org/abs/2609.04637) | 对 Qwen2-Audio 和 Qwen2.5-Omni 做 LoRA 微调前后的注意力通路分析；报告微调后 MMAR 上升而 MMAU 下降，并指出训练主要加强了后层"选项→答案"的通路 | 与本项目观察到的现象高度一致：微调伤害 MMAU；收益集中在答案选择阶段 | 本项目若走分析路线，必须在此基础上给出新东西（例如可操作的缓解办法） |
| Audio-Contribution-Aware Post-Training，[arXiv:2509.21060](https://arxiv.org/abs/2509.21060) | 按"不听音频能否答对"把数据分成弱/强音频依赖两部分；指出 MMAU 这类基准中不听音频也能答的题占比很高 | 直接关系到评测设计 | 主指标应建立在强音频依赖子集上（PROTOCOL 的 DEV-AC 即此思路） |
| Omni-R1，[arXiv:2505.09439](https://arxiv.org/abs/2505.09439) | 在 AVQA 上用 GRPO 微调 Qwen2.5-Omni 并在 MMAU/MMAR 评测；发现去掉音频只用文本微调也能涨分 | 与本项目的 AVQA→MMAU 协议同源 | 说明这个迁移协议上的涨跌很大程度与音频无关，不适合作为"音频利用"的证据 |

**小结。** "文本主导、要让模型多用音频""在最后一个 prompt token 干预""模态门控 LoRA""秩空间里的输入相关门"这四点都已有工作。CoTA 剩下可能成立的独特主张只有一个：**把"同一查询在音频 key 与文本 key 上的条件期望之差"作为低秩适配器的额外输入，是一个可学习、参数高效、且比放大注意力或普通 LoRA 更有效的音频读出方式。** 这正是 H1–H3 要检验的内容。

## 3. 对四个问题的回答

**(1) CoTA 解决哪个明确的问题？**
可以明确表述为：音频大模型在选择题式的语言决策中倾向于依据文本先验作答，即使音频信息在表示中仍然存在；普通 LoRA 微调主要改变答案选择阶段，并不保证更多地使用音频证据。CoTA 试图在作出语言决策的那个位置，把被文本压制的音频证据显式读出。
这个问题本身已有文献支持，是成立的。**尚未成立的是"CoTA 解决了它"。**

**(2) 相比已有方法的新增贡献是什么？**
目前没有已被证据支持的新增贡献。若实验支持，可主张的是 §2 小结中那一条，外加一个工程性质的发现：零初始化的乘性门在常规 PEFT 预算和 BF16 下学不动、看不见（DIAGNOSIS §1.1），这对所有"门控 LoRA"类方法都有参考价值，但单独不足以成文。

**(3) 哪些控制实验能证明贡献来自提出的机制？**

| 审稿人会问 | 对应实验 |
|---|---|
| 只是多了参数或多了一个位置专用的读出吗？ | `cota-static` vs `ctrl-ordinary`（同参数、同位置、同初始化，只换输入） |
| 和同预算 LoRA 比呢？秩从 12 降到 8 的代价呢？ | `lora-r12`、`lora-r8` |
| 减去文本均值有必要吗？和直接放大音频有何不同？ | `ctrl-audio-mean`；再加一个免训练的注意力放大基线 |
| 条件门有用吗？ | 同位置静态 vs 动态；同一检查点强制 m=1；门响应与"答案是否应随音频改变"的相关性 |
| 需要独立的 `C` 吗？ | `shared-r12`；检查点内分别去掉 `g` 路和 `C` 路 |
| 是否只是学到了时长或模板捷径？ | 跨时长、跨静音比例的保持配对与变化配对分开报告；提示改写 |
| 结果稳不稳？ | ≥3 个种子、聚类区间、预先确定的检查点、未观察的最终测试 |

**(4) 结论在什么条件下成立、什么条件下失败？**
现有数据只允许说：在与训练同分布的合成长时长配对上，传输分支对一个检查点有局部作用；在真实开发题、MMAR、MMAU、IEMOCAP 上没有可测作用；换时长分布后所有方法都大幅失效。任何更强的表述都需要新实验。

## 4. 两条可行路线

**路线 A：方法论文（取决于 H1、H2）。**
先跑 PROTOCOL 的两个主比较。如果差分读出相对 `ctrl-ordinary` 和 `lora-r12` 都有稳定优势，再依次确定：是否保留条件门（H4）、是否保留独立 `C`（H5）、是否需要改进音频内部的注意力分配（文献已提示这一点更重要）。之后才值得扩大训练和上最终测试。
风险：机制上与"放大音频注意力"系列接近，H3 若不成立，新颖性会很弱。

**路线 B：分析论文（H1、H2 被否定时的主线，也可与 A 并行）。**
现成的材料其实指向一个更扎实的题目：**小数据 PEFT 适配音频大模型时，源任务提升与目标任务受损是如何耦合的，以及能否用"只在答案位置改动模型"来解耦。** 可用的组成部分：

- 28 个方法在统一协议下的结果（需先修好退化基线并补上"对基座的改动量"度量）；
- "学会源任务的方法都掉 MMAU，没学会的都保住"这一规律（DIAGNOSIS §2.3），与已发表的现象一致但尚无人给出跨方法的系统刻画；
- 传输分支只作用于一个位置这一特性，天然适合做"位置受限适配"的对照（H6）；
- 门控学不动的数值分析，作为方法设计上的反面案例。

这条路线不依赖 CoTA 胜出，阴性结果也有信息量，且与 ACL 对分析类工作的接受度相符。风险：需要比现在大得多的开发集和更规范的统计，28 篇基线的修复有工作量。

## 5. 下一步，按性价比排序

1. **在服务器上跑通本分支的测试并确认 autocast**（不到一小时）。新代码我没能执行，这是使用它们的前提。
2. **构建 DEV-AC**（冻结基座两次评测）。没有它，后面所有比较都缺少主指标。
3. **阶段 0**：旧协议 2 臂 × 5 种子。直接回答"已有的 0.4–0.8 pp 差距是不是种子噪声"。
4. **阶段 1、2 的两个主比较**：`cota-static` 对 `lora-r12` 和 `ctrl-ordinary`。这一步决定走 A 还是 B。
5. 同时用 `adapter-stats.jsonl` 直接验证"门的梯度是噪声"这一推断。
6. 修复 LoRA-GA 的初始化数值路径，并对 PiSSA、EVA、LoRA+ 做各自的学习率搜索，再决定哪些进入论文的基线表。

在第 4 步出结果之前，不建议投入时间去设计更复杂的门（上下文化的问题表示、幅度特征、多位置注入）。如果最简单的静态差分读出都没有可测收益，在它上面加条件化也不会有。
