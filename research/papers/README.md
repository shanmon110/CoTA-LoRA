# 28 篇论文、实现与来源索引

此目录面向阅读交接仓库的 Claude/研究者，记录论文出处、当前工程的实现入口和适配边界。它是**论文方法在统一 Qwen2.5-Omni 音频协议下的实现与核验索引**；“方法已接入/已有结果”不等于复现了论文的原模型、原数据、原预算和整套实验结论。

- [catalog.json](catalog.json)：28 条机器可读记录，含官方论文 PDF、已证实作者、完整代码 commit、实现路径、配置、源码许可状态及核验依据。
- [references.bib](references.bib)：28 条 BibTeX。题名、作者和链接取自 2026-11-22 访问的官方会议页；年份采用会议年。部分 NeurIPS 2025 页面的网页发布日期是 2026 年，不能据此改写会议年份。
- 论文以官方原文链接交付；本目录不复制 PDF，也不把引用仓库、模型权重或数据集作为重新授权的附件。
- 具体执行/评估入口见 [统一驱动](../../experiments/ms_swift_aqa/papers28/run.py)、[协议](../../experiments/ms_swift_aqa/papers28/protocol.json)及[原实验说明](../../experiments/ms_swift_aqa/papers28/README.md)。机器绝对路径仍需按交接环境迁移；此索引的仓库链接均为相对路径。

## 阅读时必须保留的实验边界

1. **第 1 篇是理论复算与已知教师诊断。** [expressive.py](../../experiments/ms_swift_aqa/papers28/expressive.py) 固定作者提交、检查源码哈希并记录两处拼写修正；[known_target.py](../../experiments/ms_swift_aqa/papers28/known_target.py) 从已训练全参数教师的 Q/O 差矩阵构造局部低秩因子。后者的构造步数为零，教师训练成本独立存在；不能与普通“从冻结基座开始训练”的方法直接等同。
2. **两种 LoRAM 必须区分。** 第 9 篇 `loram-train-small` 是剪小模型、训练、补零恢复，且当前是 LoRAM-Rand 无对齐消融；第 16 篇 `magnitude-loram` 是幅值优先的初始化机制，未剪小基座。
3. **LoKRA 也不是 LoKr。** 第 28 篇是 Kruskal-rank 正则化的基础 LoKRA；不是 Kronecker LoKr，也未使用 LoKRA+。
4. **外推能力只按当前协议解释。** LongLoRA 未复测原文长上下文任务；RoLoRA 是模拟客户端；LoRAGen 仅使用四个 AVQA 专家库；aLoRA 未测跨请求缓存服务收益；LowRA 的 1.75 code bits 不代表整模型或运行内存的平均 bit 数。
5. 原始逐项说明：[1–10](../../experiments/ms_swift_aqa/papers28/sources-01-10.md)、[11–20](../../experiments/ms_swift_aqa/paper_middle_sources.md)、[21–28](../../experiments/ms_swift_aqa/papers28/sources-21-28.md)。它们包含校准、来源对照及修正细节；结果完成状态由独立实验交接证据判定，索引本身不宣称全部结果通过。
