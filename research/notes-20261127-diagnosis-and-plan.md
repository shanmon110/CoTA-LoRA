# Part 2 · 现状诊断

## 2.1 最强的五条结论

### ① 后 4 层的适配学到的是一个**类别边缘的校正**，而不是更会听 —— 而且它**零成本可修**

**证据（四条，全部本次独立复算）。**

1. **顺序差。** Session 4 上 `A-last4` 的训练顺序与其他顺序差 **+15.79 pp**（CREMA-D **+7.94**），
   而 `A-all` 是 +3.41 / −2.19，`D-all-shuffled` 是 +0.47 / −2.19。
2. **替身重构。** 三个参数替身模型（冻结基座 + 三个按字母的常量）重现了 `A-last4` 训练顺序
   增益的 **0.7922（Session 4）** / **1.6618（CREMA-D）**；替身与 `A-last4` 逐题选同一字母的
   比例 93.8%，与 `A-last4` 两个种子之间的 95.1% 相当，而基座与 `A-last4` 只有 77.0%。
3. **无标注的类别边缘校正能把它全部消掉**（本次新做，最强的一条）。
   方法：把四个选项字母的 log-softmax 按**情感**重排，按**选项顺序**分别估计模型自己的
   类别边缘（每种情感的平均 log 概率），**从无标注语音**估计后减掉，取 argmax。
   先验在一半聚类上估计、另一半评分，两个方向都算，5 次随机分半，聚类 bootstrap 2,000 次。
   结果（`research/tools/label_free_calibration.py`）：

   | | Session 4 原始 → 校正后 | CREMA-D 原始 → 校正后 |
   |---|---:|---:|
   | 冻结基座 | 55.2 → **62.7**（+7.41 [+5.08, +9.63]） | 48.0 → **60.5**（+12.58 [+10.55, +14.52]） |
   | **A-last4** | 50.4 → **62.8**（+12.34 [+10.49, +14.02]） | 46.6 → **59.3**（+12.72 [+11.17, +14.17]） |
   | A-all | 72.8 → 74.8（+2.01 [−0.03, +3.95]） | 63.5 → 70.2（+6.74 [+5.08, +8.34]） |
   | A-first4 | 70.8 → 71.9（+1.12 [−0.48, +2.87]） | 65.7 → 70.4（+4.63 [+3.43, +5.89]） |
   | A-mid4 | 68.1 → 71.3（+3.18 [+1.48, +5.52]） | 60.6 → 66.8（+6.21 [+4.54, +7.93]） |
   | D-all-shuffled | 75.8 → 75.7（−0.02 [−2.25, +1.64]） | 64.2 → 71.5（+7.23 [+5.44, +9.00]） |

   **校正后相对冻结基座的差距**：Session 4 上 `A-last4` 从 **−4.81 → +0.11**，
   CREMA-D 上从 **−1.40 → −1.26**；而多层臂仍保留 **+6 到 +13**。
   **也就是说后 4 层臂相对基座本来就没有优势，而一个无标签校正就能把它拉回持平。**

4. **而且它把顺序差也消掉了**（`research/tools/prior_correction_by_order.py`）：
   `A-last4` 的 Session 4 顺序差 **+19.6 → +1.3 pp**（seed 43：+15.3 → +2.1；
   seed 44：+13.6 → −0.1；CREMA-D：+11.7 → −1.1）。
   冻结基座自己的顺序差 −5.3 → −1.0。

**这改变机制解释。** 仓库把它读作"后 4 层学到的是按字母施加的输出偏置校正"。
但 §12.3 的 (b) vs (c) 已经说明：**按字母减没用、按情感减很有用**，
说明基座的偏向是**类别**偏向而不是**字母**偏向。而上面的校正正是把"输出偏置"和
"类别边缘"统一起来：**后 4 层学到的就是一个类别边缘**，而这个边缘**可被无标签校准抹掉**。
三个参数的替身能重现 79% 那个数字，是因为它是这个更一般、更不需要标签的校正的
**特例**（替身 = 按字母的固定偏移；校正 = 按（顺序，情感）的偏移，前者是后者的粗化版）。
**所以"替身重构了 79%"不再构成"字母偏置"这个机制的独立证据。**

**第 5 条证据（本次新做）：后 4 层臂把类别边缘"按顺序重排"了，而多层臂把边缘"校正"了。**
`research/tools/class_marginal.py` 给出每个臂在**每个选项顺序下**的类别边缘，
以及它离冻结基座、离真实分布各有多远（TV 距离）：

| Session 4 | 离真实边缘的 TV，四个顺序 | | 离基座的 TV，四个顺序 |
|---|---|---|---|
| 冻结基座 | **0.227** 0.144 0.124 **0.224** | | 0 0 0 0 |
| **A-last4** | **0.011** 0.331 0.284 0.242 | | 0.222 0.271 0.160 0.226 |
| A-all | 0.086 0.157 0.078 0.135 | | 0.184 0.144 0.094 0.207 |
| A-first4 | 0.042 0.091 0.099 0.118 | | 0.212 0.135 0.123 0.188 |
| D-all-shuffled | 0.046 0.055 0.055 0.078 | | 0.185 0.098 0.093 0.146 |

**读法（这一条把机制讲清楚了）：**

- **多层臂（`A-all`、`A-first4`、`D-all-shuffled`）**：在**四个顺序上**边缘都更接近真实
  （TV 0.04–0.21），而且它们**彼此也不同**（离基座 0.09–0.21）——**它们真的学到了内容**。
  `D-all-shuffled`（训练时打乱选项）四个顺序的边缘都几乎等于真实（0.046–0.078），
  **这正是它顺序差不塌的原因**。
- **后 4 层臂**：在**训练顺序上**的边缘是**全部臂里最准的**（TV **0.011**，比任何多层臂都好），
  在**其他三个顺序上**却是**最差的**（0.24–0.33）。它的边缘**没有被校正**，
  而是被**按训练顺序重新排布了**——**换顺序时那套排布就落到了错误的情感上**。
- 而且从整体边缘看，`A-last4` **几乎就是基座的边缘**（离基座 TV **0.017–0.023**，
  是所有臂里最小的；基座离真实 0.107）。
  **它没有学到新的先验，它只是把基座那个错的先验按训练顺序"重新贴"了一遍。**

**所以"后 4 层 = 输出偏置校正"这句话里，"校正"两个字用错了。**
它**没有**校正边缘（它的边缘整体上仍离真实 0.107，和基座一样错），
它做的是**把边缘按训练顺序重新排布**——在训练顺序上看起来对了（TV 0.011），
一换顺序就成了错配。**这是一个"记住了训练提示的对应关系"的行为，不是"校准了输出先验"。**

**强度：强。** 五条互相独立的证据，跨两个语料、跨三个种子，且第 3、4、5 条是**零成本**、
**不需要标签**、**不需要训练**的。

**可能的反驳。**
- 替身是**充分性**检验不是机制同一性；它用的正是它要解释的那个顺序上拟合的常数。
- 校正**用到了类别标签的先验结构**（四类等可能）——但它**不需要知道真实类别频率**，
  只用模型自己的边缘，而且用的是**未标注**的语音。这一点要在论文里说清楚，
  因为 Peng & Nuchged 的同一家族方法正是这一点上最容易被质疑。
- 校正只覆盖**这个固定四类、四个顺序**的任务；它没有证明音频信息被丢掉了。
- 单一基座、单一语料、单一训练方式。
- `A-last4` 的"同一情感跨四个顺序"比例只有 **37.5%（Session 4）/ 43.7%（CREMA-D）**，
  其他臂 69–87%——它确实在"塌"；而校正**没有完全消除**这个塌陷
  （顺序差从 +19.6 到 +1.3，不是到 0）。所以"塌"里有一小部分不是类别边缘。

### ② 音频里的情感信息到了模型内部，但没有被答案用上（至少在 Session 4 上）

**证据。** 冻结基座在 Session 4 上的答案 56.1%，而同一批语音上音频位的线性探针 76.5%
（打乱标签对照 25.6%），答案位探针 74.6%。差 **20.4 pp**。

**强度：中。** 只在一个语料上成立，且探针是有监督的、答案是零样本的。

**可能的反驳。**
- **CREMA-D 上同样的探针只有 33.4%（对照 24.2%）**。仓库的 `summary/probes.json` 已经把
  CREMA-D 的读法写成 `perception_use_gap: "unclear"`，但交接文档在陈述时只提了 Session 4。
  **这条结论的适用范围是"Session 4"，不能笼统说"语音 LLM 听到了不用"。**
- 报告用的探针层是在 dev 上选的，逐语料最优层更高（CREMA-D 答案位 L36 = 59.5，报告用 L32 = 54.9）。
- 探针只能证明信息**线性可解码**，不能证明模型"本可以"零样本答对。

### ③ AQA 上的负迁移是真的，而且不能靠推断期门控解决

**证据。** 四个臂在 MMAU 上全部低于冻结基座（原顺序 −2.2 / −3.9 / −0.3 / −2.9，区间只有
`AQ-last4` 含 0）；**分域、分源、文本格式下全部净负**（AQ-all music −4.34、sound −2.65、
speech −1.54，净翻转 −58 / −32 / −21）。带标签的 **domain 级 oracle 上限是 0.00 pp**；
source 级 oracle 上限只有 +0.91 到 +3.75 pp；**诚实 split-half CV 的留出增益全部 ≤ 0**
（−0.38 到 +0.00），规则在多数折上选择"永不使用适配器"。

**强度：强。** 预先声明的判据、三个种子、五个以上的切分方式、区间。**这条是本项目最硬的结果。**

**可能的反驳。**
- MMAU 已经被探索性看过（`CLAUDE.md` 自陈），这部分只能算探索性证据。
- 训练用的是 AVQA，评测用的是 MMAU，**两个语料的任务格式不同**（AVQA 是音频问答，
  MMAU Test-mini 有 music/sound/speech 三个域）。"负迁移"里有多少是"跨语料"、
  多少是"跨任务"，目前没有分开测。
- 最优固定字母重映射的上界是 +0.00（music/sound）、−0.55（speech），**所以它不是答案字母
  先验的假象**——这一点反而加强了这条结论。

### ④ 后 4 层的位置效应在跨任务上不成立；在 AVQA 上四个臂都是负的

**证据。** 在 AQA 上，四个臂（first4 / mid4 / last4 / all，三个种子）**全部读作 `no gain`**；
顺序差全部落在冻结基座自己的 +1.32 附近（0.39–1.36），**没有一个明显超过基座**。

**强度：中。** 四个臂 × 三个种子 × 四种顺序 × 两种格式，样本量够；但这是唯一一次跨任务检验。

**可能的反驳。**
- 开发集准确率与 MMAU 准确率的相关是 **−0.9063（全部顺序）/ −0.8442（原顺序）**，
  但**去掉三个训练最少的 `AQ-last4` 臂后塌到 −0.3042 / −0.0769**。
  **这条负相关是由欠拟合的臂撑起来的**，它说明的是"开发集选不出好臂"，不是"训练越少迁移越好"。
  仓库的 `NOTES.md` 写了"主要由 AQ-last4 撑着"，但结论句没有带上这个限定。
- `AQ-last4` 开发集准确率只有 0.734–0.742（其他臂 0.81–0.84），它"最不掉队"很可能只是
  **训得最少**，而不是"绑定得更紧"。这一条目前**没有证据支持也没有证据排除**。

### ⑤ 后 4 层的"顺序敏感"是**类锚定**的，不是字母锚定的（本次重算新发现）

**证据。** 用 `research/tools/slot_vs_class_anchor.py` 把每个臂在四个选项顺序下的
**槽位分布**和**类别分布**并排打出来：

| 臂（Session 4） | 每个顺序下最偏好的槽位 | 每个顺序下最偏好的类别 | 任一顺序下的槽位峰值 |
|---|---|---|---|
| 冻结基座 | A / C / C / B | angry / neutral / angry / angry | 54.3% |
| A-all | A / D / C / B | **angry / angry / angry / angry** | 44.2% |
| A-first4 | A / D / C / B | **angry / angry / angry / angry** | 45.2% |
| A-mid4 | D / D / C / B | neutral / angry / angry / angry | 44.6% |
| **A-last4** | **A / C / C / B** | **angry / neutral / angry / angry** | **68.2%** |
| D-all-shuffled | A / D / C / A | angry / angry / angry / neutral | 36.0% |

**关键观察：`A-last4` 的槽位偏好模式与冻结基座完全相同（A / C / C / B）**，
而**所有适配过的臂的模式都变了**（`A-all`、`A-first4` 都变成 A / D / C / B）。
同时 `A-last4` 在三个种子上的槽位峰值（68.2 / 63.5 / 62.0）**接近替身的 67.3%**，
而其他臂（44–45%）**远低于**替身。

**这条为什么重要。** 一个纯字母偏置（每槽一个常数）只能产生**槽位锚定**的行为。
`A-last4` 与冻结基座的槽位模式相同这一点，**不能区分"字母偏置"和"类偏置"**——
因为在训练顺序下两者恰好重合。但在**其他三个顺序**上它们分开了：
`A-last4` 的槽位峰值（68.2%）几乎等于替身（67.3%），**说明 `A-last4` 塌向固定槽位**，
而 `A-all` 塌向固定类别（四个顺序下都是 angry）。

**这条同时收窄了 §2.1 ① 和 ⑤ 两条结论**：后 4 层的行为里有**两个不同的成分**——
一个**继承自基座的槽位偏置**（与基座模式相同，替身能重构）和一个**新学的类偏置**
（`A-all`/`A-first4` 表现出来的、跨顺序恒定的 angry 偏好）。
替身只重构了前者。

**强度：中。** 只在情感任务（固定四类、训练顺序固定）上可测；AQA 上没有固定类—字母对应，
无法做同一个检验。

**可能的反驳。**
- 替身是**在训练顺序上拟合**的，它在训练顺序上的槽位模式必然与基座相同，所以
  "A-last4 的 r0 与基座相同"这一条**没有信息量**；有信息量的是 r1–r3 的对比。
- 四个顺序的样本不独立（同一批语音），峰值的比较没有区间。
- `A-last4` 的槽位峰值接近替身，也可能是"两者都接近饱和"（替身在 CREMA-D 上峰值 87.2%，
  比 `A-last4` 的 86.8% 还高），所以"接近"可能是饱和效应而不是结构相同。

### ⑥ 三参数替身模型能用极小的自由度解释后 4 层的大部分行为

**证据。** 替身（4 个 logit 各加一个常数、和为零、在训练顺序上按类别加权似然拟合）重现了
`A-last4` 的增益、损失、以及换顺序时"塌"的方式（同一字母 15.2% 对 15.1%、同一情感 63.0%
对 60.6%）。

**强度：中—强。** 三个自由度解释一个 131,104 参数适配器的行为，这是一个有说服力的简约性论证。
但它同时也是一个**否定性**结论：它说明后 4 层的适配器**没有学到更多**，只是学了一个输出偏置。

**可能的反驳。**
- 替身参数是在**被解释的那个顺序上**拟合的（`letter-bias-20261125.md` 自己承认）。
- 它解释了"输出偏置校正"这一层，但**没有解释内容层面的退化**：
  `A-last4` 的内容准确率（答案的情感是否正确）在 Session 4 上是 56.6%，**低于冻结基座的 61.2%**。
  也就是说后 4 层不只是加偏置，它**还损坏了内容判别**。替身无法解释这一点。

## 2.2 最弱的五条结论

### ① "敏感但未校准"（展平 F0/能量的逐类移动）

**为什么弱。** 逐类数字精确复现（angry −8.3 / happy +5.4 / sad +8.0 / neutral −9.8），但**同一次
运行的闸门写的是 `flattening_keeps_words: fail`**（展平后词错率 8.95% → 12.90%）、
`f0_energy_use: not_interpretable`、`level_both_use: not_interpretable`、
`neutral_use: not_interpretable`；每个条件的 UAR 差都 ≤ 1.2 pp，区间全部跨 0。
**运行自己禁止了这个读法**，而交接文档陈述时没有带上这个限制。

**审稿人会怎么打。**"你用一个把词也改坏了的音频对照，去论证模型对韵律敏感。你的'敏感'和
'词被改坏了'不可分离。这不是 prosody ablation，是输入损坏。"——**这一条基本无法辩护**，
除非补一个能保持词的展平对照（Praat 的周期叠加、或用同 F0 不同能量的句子对）。

### ④ 开发集准确率与 MMAU 准确率负相关（−0.84 / −0.43）

**为什么弱。** 数字本身**完全正确**（我重算 −0.8442 / −0.4336，原顺序口径），但：

**审稿人会怎么打。**"12 个点里有 9 个来自四个高度相似的臂，Spearman −0.08。你报告的负相关

### P0b · 在 AQA 上做"槽位锚定 vs 类锚定"的同一个检验（零训练成本，半天）

**它决定什么。** 决定 §2.1 ⑤ 那条新发现能不能推广。AQA 上每题选项都不同，**没有固定的
类—字母对应**，所以"类锚定"在 AQA 上只能定义为"对同一批题的正确答案位置（相对选项的语义
位置）有偏"——这恰恰是 AQA 的 MCQ **可以**测的：如果适配器在 AQA 上也偏向某个**答案字母**
（而不是偏向某类内容），那么 AQA 的负迁移就有一部分是**位置捷径**；如果它偏向的是**选项的
语义**（例如总是选最长的选项），那是另一种捷径。

**做法。** 用已跟踪的 AQA 逐题答案（`mmau/runs/*/mcq/predictions.jsonl`，零额外成本）：
1. 算每个臂选每个字母的比例，与 gold 字母的比例对照（`aqa_letter_prior.py` 已有工具）；
2. 算每个臂选的选项在**语义维度**上的分布（长度、是否含数字、是否是"以上都对"这类），
   与冻结基座对照；
3. 把负翻转的题按"适配器是否改了字母"分层，看负迁移落在"改了字母但字母不对"还是
   "字母没改但内容错了"。

**预声明判据。**
- 若负迁移的题**主要是字母变了且变错**（而不是字母没变内容变错），则 AQA 的负迁移
  **部分**是位置捷径 → 第 5 章的结论要分成"位置捷径"和"内容退化"两半。
- 若负迁移的题**主要是字母没变、内容变错**，则负迁移**不是**位置捷径，
  而是表示层的退化 → 支持"后 4 层损坏了内容判别"这个更一般的说法。

**成本。** 零 GPU、零训练、全部只读。**现有材料够**（AQA 的逐题预测已全部跟踪）。

**是否已被现有结论证伪。** 没有。这是**零成本**且能直接决定第 5 章怎么写的一条。

## 4.2 需要**降级**（不是推翻）的一条方法学结论

### 4.2.0 最重要的一条：**"输出偏置"和"类别边缘"是同一件事**，必须合并表述

**这是本次复核后对机制解释的实质性修改，不是补充。**

仓库原来的读法：后 4 层学到的是"**针对训练提示的输出偏置校正**，校正量按**字母**施加"。
证据是三个参数的字母替身能重现 79% 的增益。

**但 `origin/main` 的 `d8eda26`（本地 `main` 未收到）里有一项**按情感**的无标注校正，
它把后 4 层臂的顺序差从 +19.6 拉到 +1.3 pp，相对基座的差距从 −4.81 拉到 +0.11，
而**替身和校正叠加反而变差**（52.4 vs 单用校正 64.0）。**

**这说明替身不是一个独立的机制解释，而是同一个更一般解释的特例：**

| 解释 | 施加的偏移 | 需要标签吗 | 标签 | 效果 |
|---|---|---|---|---|
| 三个参数字母替身 | 每个**字母**一个固定常数 | 需要（拟合用训练顺序的 gold） | 3 个 | Session 4 训练顺序 51.6 → 61.5 |
| 无标注情感先验校正 | 每个**（选项顺序，情感）**一个常数 | **不需要** | 0 个 | Session 4 55.2 → 62.7，顺序差 +19.6 → +1.3 |

在这个固定四类的任务上，后者**严格更一般**：前者是后者在"只按字母、不按顺序"上的粗化版。
**所以正确的表述是：**

> 后 4 层学到的是一个**类别边缘**（class marginal），它在训练顺序上被校正到了接近真实分布，
> 换顺序后被施加到错误的情感上。它**不是**"按字母施加的偏置"——
> §12.3 的 (b) vs (c) 已经说明按字母减没用、按情感减有用。
> 而且这个边缘**可以用几十段无标注语音估计并消掉**，不需要任何标签、不需要任何训练。

**这条把"后 4 层到底学了什么"从一个开放问题变成一个有答案、有对照、可复现的问题。**
它也是第 4 章的核心论点，而且它把"后 4 层"这个现象**从"一个微调现象"提升为
"任何有输出先验的任务都会遇到的一般现象"**——这正是分析论文该有的贡献。

**必须同时说明的边界。** 校正**没有完全消除**塌陷（顺序差 +19.6 → +1.3，不是 0），
而且 `A-last4` 的内容准确率低于基座（56.6 对 61.2，见 4.2(b)），
**说明"塌"里还有一部分不是类别边缘。** 论文必须如实写这一点。

### 4.2.1 收窄

**"后 4 层学到的是输出偏置校正"** 这条结论**成立**，但**表述需要收窄**：

- 它现在只覆盖**一个固定标签、训练时选项顺序固定**的任务。交接文档自己写了这一点，正确。
- 但补两条新证据：

  **(a) 后 4 层的行为里有两种成分，替身只覆盖一种。** 见 §2.1 ⑤：`A-last4` 的槽位偏好模式
  与冻结基座完全相同（A / C / C / B），而所有适配过的臂都变了（`A-all`、`A-first4` 变成
  A / D / C / B）。在训练顺序下"槽位锚定"和"类锚定"重合，所以只有 r1–r3 能区分它们，
  而 r1–r3 上 `A-last4` 的槽位峰值（68.2%）几乎等于替身（67.3%），
  `A-all`（44.2%）远低于替身。也就是说：**`A-last4` 塌向固定槽位（替身能重构），
  `A-all` 塌向固定类别（替身不能）**。替身重构的是"继承自基座的槽位偏置"，
  不是"新学的类偏置"。

  **(b) `A-last4` 的内容准确率在 Session 4 上是 56.6%，低于冻结基座的 61.2%**。
  也就是说后 4 层**不只是加了偏置，它还损坏了内容判别**（而且"跨四种顺序选同一情感"只有
  37.5%，其他臂 69–87%）。**替身模型解释了"塌向固定字母"，但解释不了"内容判别下降"。**

  所以正确的表述是：
  > 后 4 层的适配可以用三个自由度的输出偏置重构它的**槽位锚定行为**；
  > 但它**新学了一个跨顺序恒定的类偏置**（`A-all` 式的 angry 偏好），
  > 而且**它的内容判别比基座更差**（−4.6 pp）。这两部分都不在替身里。

  这不是推翻，是把结论的边界划清楚——而**划清边界本身就是分析论文的贡献**。

- 顺带一条**对论文有用的正面结果**：**去掉槽位偏好后，`A-last4` 的 UAR 从 50.97 升到 56.16
  （+5.19 pp），而其他臂几乎不变**（`A-all` +0.52、`A-first4` +0.06、`A-mid4` +0.68、
  `D-all-shuffled` −0.35、冻结基座 +0.22）。也就是说 **后 4 层的损伤里有一半是"位置偏置"，
  这一半是可以在推断期修好的**（虽然 A2 已证明在 AQA 上门控没有空间）。
  这给第 4 章一个"我们能修多少"的具体数字。

## 4.3 路线判断：**这篇论文应该是分析论文，不是方法论文**

**直接回答：是的，应该转为分析论文（Route B）。** 理由：

1. **方法路线已经被六个方向的证伪结果关死了。** 条件门（数值惰性）、TRR 孪生读出（前提不成立）、
   位置受限 LoRA（与打乱选项打平）、输入条件化适配分配（三种分组都无余量）、A2 域条件门控
   （oracle 上限 0.00 pp、split-half CV 全部 ≤ 0）、跨格式/跨语料差（已被排除）——
   **没有一个留下可争取的空间**，而且**新加的分析测量（P1）反而显示基线还能再涨 8.7 pp**
   （CREMA-D 上的先验校正），也就是说**基线本身还没被做扎实**，谈方法为时过早。
2. **文献已经占据了方法位置。** "针对副语言感知的微调方法"这一格有 Pang 2026（多层聚合 +
   偏好优化，VoxParadox 17.4% → 65.2%）、Yang 2026（只用副语言层 + 辅助分类头，
   情感 0.393 → 0.503）、"Heard but Not Heeded" §6.5 的辅助目标方向（明确未验证）、
   以及 CoTA 本身（当前版本的 TA 门在数值上惰性、量级与 Adam 随机游走相当）。
   **我们的方法侧没有可防守的位置。**
3. **分析侧反而有一个别人没有的位置，而且我们已经有了大部分证据。** 三篇威胁论文
   （2608.06409 / 2610.25599 / 2609.00727）都**没有做"微调后的适配器在选项顺序下的行为，
   作为适配位置的函数"**；Cho 2026 做了层段但没打乱选项；Lin 2025 / López 2025 做了选项顺序
   但只评现成模型。**"适配位置 × 选项顺序"这个交叉点是空的**，而我们有：
   - 四个层段 × 三个种子 × 四个选项顺序 × 两个语料；
   - 一个三自由度的替身模型证明后段行为可以被输出偏置重构；
   - 一个可复现的先验校正基线；
   - 一个跨任务的负迁移定位。

### 论文骨架

**题目（暂定）。** *Where does a speech LLM's fine-tuning shortcut live? Adaptation depth,
option order, and the output prior in audio-language models*

**第 1 章 · 引言。** 贡献点三条：
1. **一个可复现的协议**：把"适配器的选项顺序依赖"当作适配位置的函数来测（层段 × 顺序 ×
   多种子 × 跨语料），并给出三个自由度的**替身重构**作为判别工具。
2. **一条定位清楚的负结果**：微调后的适配器在音频问答上**净负迁移**，且这**不能**用答案
   字母先验、**不能**用推断期门控（oracle 上限 0.00 pp、split-half CV ≤ 0）、
   **不能**用域条件化解释；负迁移的位置在**数据层**。
3. **一条基线校正**：输出先验校正在冻结模型上给 +8.7 pp，而在适配后的模型上**有害**——
   这个不对称本身就是"适配器学到了什么"的证据。

**第 2 章 · 相关工作与定位。**
- 已有："听到却不用"（Koduru 2026 §6.4 GRL 失败、§6.5 辅助目标未验证）；"决策规则 vs 读出

**第 3 章 · 测量协议。** 语料、层段、选项顺序的拉丁方、多种子、聚类 bootstrap、
区间口径（source 为单位、种子联合）、**预先声明的判读规则**（这一章是这篇论文的信誉基础，
现有仓库里已经有五份声明文档，直接整理）。

**这一章必须先写清楚的一件事（本次源码级复核的结果，
见 `research/notes-20261128-source-review.md`）：**
**本文所有臂的 `gate_multiplier` 都是 0.0，传输项是可证明的恒等 no-op。**
所以本文测的是**「把一个 r=8 的低秩更新放在哪些层」**，
**不是**「CoTA 的传输机制放在哪些层」。
表格里的臂名必须加限定（例如写成 "low-rank update, last 4 layers" 而不是 "CoTA last 4 layers"），
**否则就是误述方法**。传输机制本身在本文里没有被测过，
要谈它必须另做实验并单独报告。

**这一条现在有三条互相独立的证据**（读源码 / 数值复现 / 训练本身写的优化器状态），
而且**比"传输项是 no-op"更强**：

**历史臂连独立 C 项都没有。** 审计显示全部历史臂每层只存了 `down`、`up`、`gate` 三个因子，
**没有 `transport_up`（C），没有 `gate_weight`**。
在 `_SharedAtoms._project` 里，传输分支是

```python
update = F.linear(coeff, self.up)
if self.transport_up is not None:
    update = update + F.linear(extra, self.transport_up)
```

**C 这一条通路根本不过门项。**
所以历史臂是**双重缺席**：共享门项被乘子关掉，独立 C 项压根没建。
CLAUDE.md 说"完整关闭传输需关闭共享门项和独立 C 项"——历史臂**两项都关了**。

**因此历史臂在数学上与「普通 r=8 LoRA」完全等价。**
这一句必须写进第 3 章：**本文的 44 个臂就是 44 个普通 LoRA**，
只不过放在不同的层段、不同的种子、不同的语料上。
这不是本文的缺陷——**本文本来要测的就是"低秩更新放在哪里"**——
但**必须在正文里说清楚**，否则整篇论文会被读成在测一个它并没有测的方法。

**并且必须说清楚功劳该记在哪：** 在数值真正生效的配置下实测，
**独立 C 的量级（|.| ≈ 15）远大于门项（|.| ≈ 1e-3）**，
而 C 这一条通路上没有门项——
**所以"传输机制"真正起作用的是独立 C，不是那个条件门。**
条件门是 `coeff + gate * extra` 里的加号项，量级比 C 小几个数量级。
**如果只测条件门，就会把功劳记错地方。**

**第 4 章 · 后段学到的是一个类别边缘。**（**本章是全文的核心，合并了原来的"输出偏置"章
和"输出先验"章的一部分**）
- 证据：`A-last4` 顺序差 +15.79 / +7.94；替身 3 自由度重构 0.7922 / 1.6618；
  逐题同一字母 93.8% 对种子间 95.1%。
- **主证据（本次新增）**：**一个不需要标签的类别边缘校正把这一切消掉**——
  Session 4 上 `A-last4` 顺序差 +19.6 → +1.3、相对基座 −4.81 → +0.11；
  CREMA-D 上 +11.7 → −1.1、−1.40 → −1.26。
- **确认证据（本次新增，本章的最强一条）**：**在第三个语料上确认**——
  IEMOCAP **Session 5**（没有参与过方法选择）上，校正后后 4 层臂族相对校正后基座
  **−0.82 pp**、校正后顺序差 **−0.72 pp**，预声明判据（|gap| < 2 pp、|顺序差| < 5 pp）

**第 5 章 · 负迁移的定位。**
- AQA 四个臂全负；分域净负；**固定字母重映射上界 0.00 pp**（不是字母假象）；

  **所以负迁移测量的是 AVQA → MMAU 的迁移代价，不是适配器在第二个任务上的能力上限。**
  **两个任务对基座几乎一样难（74.44% 对 74.91%），"跨任务不可比"在基座这一层就不成立。**
- **这个增益在四个选项序上是均匀的（本次新增，不是位置假象）：**

  | shift 3 | 3,001 | 74.81 | 82.44 | **+7.63** |

  **顺序差几乎没变：基座 1.37 pp，`AQ-all` 1.50 pp。**
  **增益不是靠某一个选项序吃到的**，所以它不是"字母/位置"那类假象
  （和 §4.2.2(b) 的 P0b 一致）。
- **第二个臂落地（`AQ-last4`）：**

  | | 留出 AVQA（同分布） | MMAU（跨语料） |
  |---|---:|---:|
  | 冻结基座 | 74.44% | 74.91% |
  | `AQ-all` | 81.71%（**+7.27** [+6.31, +8.25]） | 72.10%（−2.81） |
  | `AQ-last4` | 74.53%（**+0.08** [−0.26, +0.42]） | 74.35%（−0.56 [−1.17, +0.05]） |

  **两个臂的读法完全一致，而且它把"层段"和"迁移"彻底分开了：**
  - `AQ-all`（36 层）：同分布 **+7.27**，跨语料 **−2.81** → **学到了很多，迁移不掉**；
  - `AQ-last4`（后 4 层）：同分布 **+0.08**（区间含 0），跨语料 **−0.56**（区间含 0）→
    **既没学到什么，也几乎没坏**。

  **所以"多层臂在第二个任务上负迁移"这个说法本身要改写：**
  **那不是"多层这个位置不好"，而是"多层臂学到了更多，因而有更多可以迁移不掉的东西"。**
  **后 4 层臂在两个任务上都是持平的。**
  **这条直接改变第 5 章的结论方向：**
  **层段的选择不该按"迁移后掉多少"来定，该按"同分布上学到了多少、迁移不掉多少"来定。**
  **剩余 10 个臂跑完后逐臂复核这一读法。**
- **同一条分层在留出 AVQA 上跑，方向整个反过来（本次新增，最强的一条机制证据）：**

  分层还是用**冻结基座自己的 text 格式答案**：
  2,116 题"不看音频基座就能答对"，885 题"必须听音频"。

  | | 留出 AVQA：不看音频也能答的 | 留出 AVQA：需要音频 |
  |---|---:|---:|
  | 冻结基座 | 90.1% | 37.0% |
  | `AQ-all` | **92.9%**（+2.8） | **55.1%**（**+18.1**） |
  | `AQ-last4` | 89.9%（−0.2） | 37.8%（+0.8） |

  **在 MMAU 上，臂在"需要音频"的那一层丢得最狠（丢失率 +20 到 +29 pp）；**
  **在同分布的留出 AVQA 上，臂在"需要音频"的那一层涨得最多（+18.1 pp），**
  **而在"不看音频也能答"的那一层几乎不动（+2.8 pp）。**

  **同一个分层、同一个代理，方向完全相反——**
  **所以那不是"音频通路被破坏"，而是"音频通路的表征被重写成了对源语料音频更有效的"。**
  **这条把步骤 1 的读法从"伤害"升级成了"特化"，而且是零成本的。**

  **但必须把话说完整（这是混杂的另一半）：**
  在"需要音频"那一层里，臂**既丢又修**——把这一层按基座答对/答错分开看：

  | | MMAU（跨语料） | 留出 AVQA（同分布） |
  |---|---|---|
  | 基座答对、臂答错 | 丢失率 **33.7%** | 丢失率 **15.5%** |
  | 基座答错、臂答对 | 修复率 **9.9%** | 修复率 **36.6%** |

  **所以不是"伤害消失了"，而是"丢失减半、修复涨了三倍半"。**
  **在同分布上，这个臂在音频题上的净效应是大正（+19.1 pp），
  而在跨语料上是净负（−4.8 pp）。**

  **结论的正确写法：** 这个臂**没有**在音频通路上退步；
  它在源语料的音频上学到了更好的判别，
  **但它把原来会答对的那一部分也弄丢了一些**（跨语料时丢得更多，因为基座的强边缘没有跟着迁移）。
  **这正好和第 4 章的类别边缘是同一件事：**
  **适配器用一个更平的边缘覆盖了基座那个强的边缘**，
  在源语料上覆盖得好（+19.1），在别的语料上覆盖得差（−4.8）。
  **第 4 章和第 5 章在这里合成了一条线。**
- **第 5 章的归因因此改写（且更简单）：**
  **负迁移 = 适配器学到了对源语料音频的特化，而它迁移不到目标语料。**
  和步骤 1 合起来：伤害落在**需要音频**的题上，**但只在迁移时出现**——
  同分布上适配器是变好的。
  **代价：AQA 上的层段排序不能用来支持或否定层段主张，
  因为层段问题在第二个任务上根本没被测过。**
  **这一步不训练任何东西，全是推理。**

**第 6 章 · 输出先验与基线（**这一章现在大部分已经做完了**）。**
- **无标注类别边缘校正，在每一个臂上，带区间**（本次全部做完）：

  **Session 4 基本没有增益**（`A-all` +2.01 [−0.03, +3.95]，`D-all-shuffled` −0.02），

**还有一个必须说清楚的边界（本次源码级复核的结果）：**
**本文所有臂的 `gate_multiplier` 都是 0，传输项是可证明的 no-op**（见
`research/notes-20261128-source-review.md` §2，三条独立证据：读源码 / 数值复现 /
**训练循环自己写的优化器状态——全部 44 个臂、144 个门参数，0 个有状态**）。
**而且历史臂连独立 C 项都没有**（每层只存 `down`/`up`/`gate` 三个因子），
**所以历史臂在数学上与普通 r=8 LoRA 完全等价**。

**所以本文测的是「r=8 低秩更新放在哪些层」，不是「CoTA 传输机制放在哪些层」。**
这**不是本文的缺陷**（本文要测的就是低秩更新的位置），
**但正文必须写清楚**，否则会被读成在测一个它并没有测的方法。

而且**匹配 LoRA 对照（`lora-r12`，r12/alpha24）从未训练**——
`experiments/cota_review/` 只有 8 个臂的配置，**一个结果都没有**。
**所以本文是「低秩更新 vs 冻结基座」，不是「CoTA vs 匹配 LoRA」，论文不能声称后者。**

**这一条正在被补上（Q7）：** 三个臂——匹配 LoRA（r12/alpha24）、
参数匹配 LoRA（r8/alpha16，与 36 层臂只差 36×8 个门参数）、
以及**传输臂在数值上真正生效的配置**（multiplier 1 + FP32 传输通路 + 16× 门学习率）。
**判据写在跑之前**：修正后的基线上，传输臂比匹配 LoRA 高**超过 2 pp** 才是方法贡献；
否则**传输线关闭**，本文就是它已经是的分析论文。**"没有增益"是合法结果，照记不误。**

**并且新增了一个此前没人做过的零成本测量（`research/tools/transport_effect.py`）：**
同一套权重、同一批真实音频打两遍，一遍传输项开着、一遍乘子设 0（**只关传输项**），
比较两遍的答案。**它回答的是"传输机制到底改变了什么"**，
而且**它同时给出了一个必须说清楚的观察：独立 C 的量级（|.| ≈ 15）
远大于门项（|.| ≈ 1e-3），而 C 这一条通路上没有门项**——
**真正起作用的是独立 C，不是那个条件门。只测条件门会把功劳记错地方。**

## 4.4 明确**不建议**做的

- 不要在 AQA 上再加层段臂（当前 AQA 的一切都是 `no gain`，加臂只会再加四个 `no gain`）；
- 不要重提 CoTA 的条件门、TRR、位置受限 LoRA、输入条件化分配、A2 门控、跨格式差
  （六个已证伪方向）；
- 不要做"辅助风格预测目标"作为方法主张（"Heard but Not Heeded" §6.5 已提出且明确未验证，
  且他们的 GRL 实验已失败说明线性解纠缠走不通）；
- 不要用展平 F0/能量的结果支持任何韵律结论（运行自己的闸门禁止）；
- 不要在论文里报告 AQA 的 text 列而不声明打分规则（严格与宽松会改变结论方向）。
